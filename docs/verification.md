| CloudFormation Guard 3.2.1 | 앱·DB 템플릿의 프로젝트 보안 규칙 통과 |

PostgreSQL 동시성 시험은 동일 이벤트 6개 동시 수신, 동일 클립 6개 동시 요청, 중복 큐 메시지의 동시 claim을 실행했다. 각각 이벤트 한 건, 활성 작업 한 건, 유효 lease 한 개만 남는 것을 확인했다. AWS 호출은 테스트 대역·botocore Stubber를 사용했다. 실제 AWS 통합 시험 결과로 간주하지 않는다.

현재 의존성의 Starlette TestClient에서 HTTPX 사용에 대한 폐기 예정 경고 1건이 발생한다. 시험 실패는 아니며 향후 테스트 클라이언트 전환 시 다룬다.

## 범위

AWS 리소스 생성, 실환경 회사 계정 연동, 현장 서비스 설치, 파트너 소비자 인수, 부하 시험과 재해 복구 측정은 수행하지 않았다. 필요한 환경값과 절차는 `deployment.md`에 있다. 템플릿의 계정별 배포 검증은 실제 계정·리전·VPC·인증서·권한을 가진 배포 단계에서 수행한다.

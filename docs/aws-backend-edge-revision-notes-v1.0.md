# AWS 백엔드 및 엣지 에이전트 규격서 개정 내역

대상 버전 1.0　개정일 2026년 11월 7일

본 파일은 검토용 개정 기록이다. 업무용 규격서 본문과 분리해 관리한다.

## 문서 구성 변경

| 구분 | 이전 문서 | 버전 1.0 |
|---|---|---|
| 작성 경위 | PPT 파일명, 우선 슬라이드와 해석 설명 | 본문에서 삭제 |
| 문체 | 원안 유지, 보완 제안, 협의 필요와 변경 사유 중심 | 담당자가 따라야 할 규칙과 응답 조건 중심 |
| 형식 | 색이 있는 표와 텍스트 중심 | 흰 배경, 검정 글자와 선, 시각적 다이어그램 |
| 그림 | 없음 | 아키텍처, 이벤트 흐름, 클립 흐름, 작업 상태 전이 |
| 미정 항목 | 협의 사항 표 | 배포 매니페스트의 필수 환경값과 운영 책임으로 정리 |
| 기본값 | 초기 제안값 표 | 버전 1.0의 조정 가능한 기본 동작 설정으로 정의 |
| 변경 이력 | 본문에 원안 대비 변경표 | 본 파일로 분리 |

## 기술 규격 변경

| 항목 | 변경 내용 | 영향 |
|---|---|---|
| 로컬 AI 연동 | 원자적 JSON 파일 inbox와 accepted 및 rejected 처리 정의 | 새로운 로컬 접수 계약. AI 및 녹화 프로그램에서 파일 출력 필요 |
| 클립 상태 순서 | 이벤트 ACK 후 revision별 클립 상태를 전송하도록 명시 | 이벤트보다 상태가 먼저 도착하는 문제 방지 |
| AVAILABLE 필드 | 시작과 종료 시각, 형식 및 크기 필수 | 생성 완료와 단순 상태 표기를 구분 |
| API 추적 | 오류 requestId를 traceId로 변경 | 영상 작업 requestId와 호출 추적 식별자 구분 |
| 이벤트 표 | 18개 코드를 유지하고 301~303을 개별 행으로 표시 | 코드 변경 없음 |
| 데이터 구조 | 논리 테이블과 유일성 및 트랜잭션 제약 추가 | DB 제품과 관계없이 필요한 무결성 명시 |
| 파트너 권한 | 기본 AAS 공개와 명시적으로 허용한 이력·영상 권한을 구분 | 승인된 grants에 따라 확장 가능. 자동 영상 공개 없음 |
| 다중 자산 권한 | 센터 전체 또는 모든 연결 자산 읽기 권한을 요구 | 일부 허용 자산을 통해 이벤트 전체가 노출되는 상황 방지 |
| AAS | v3.1.2 직렬화와 고정 스키마·매핑 산출물 규정 | 표준 스키마 검증을 인수 기준에 포함 |
| 검수 | 로컬 inbox와 부분 파일 시험 추가 | 총 17개 검수 항목 |

이벤트 중심 클라우드 저장, NAS 원본 보관, AAS 읽기 어댑터, 아웃바운드 통신, 에이전트 작업 API, 온디맨드 S3 클립 전달은 유지했다. 자동 격리, AMR 제어와 라이브 스트리밍을 추가하지 않았다.

문서의 기본값은 신규 규격의 동작 기준이며 기존 현장의 실측치나 승인된 SLA를 의미하지 않는다. 실제 센터와 장비 값, 보관 기간, DB 제품, 용량 및 장애 연락은 배포 매니페스트에서 관리한다.
